# Local Mini App illustrations

Microsoft Fluent Emoji, MIT license (see LICENSE.txt).
Source: https://github.com/microsoft/fluentui-emoji

3D PNG originals converted to 256×256 WebP at quality 0.9, preserving alpha; no product photos or user portraits.

chart: Chart increasing
collaboration: Handshake
shopping: Shopping bags
goods: Package
calendar: Calendar
receipt: Receipt
accounts: Card file box

Used decoratively, with empty alt text. All files are served locally; no runtime third-party image requests.
